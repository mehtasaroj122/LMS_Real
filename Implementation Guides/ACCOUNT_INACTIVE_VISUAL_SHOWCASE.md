## 🎯 User Experience Journey

### Step 1: User Tries to Login
```
┌─────────────────────┐
│   Login Form        │
│ Email: inactive@... │
│ Password: ****      │
│ [Login Button]      │
└─────────────────────┘
        ↓
   Submit Form
```

### Step 2: System Validates
```
Check user exists?
        ↓ Yes
Check status = inactive?
        ↓ Yes
Throw validation exception
        ↓
Controller catches
```

### Step 3: Show Error Page
```
┌──────────────────────────┐
│  Account Inactive Page   │
│  (This beautiful page!)  │
│  Contact admin message   │
│  Navigation buttons      │
└──────────────────────────┘
        ↓
User can:
✓ Contact admin
✓ Go back to login
✓ Create new account
```
